PayStream API

PayStream lets you bill customers with invoices and payment links. The API is REST over HTTPS in production and plain HTTP in the sandbox, with JSON bodies.

Authentication

Send your secret key in the Authorization header as a bearer token:

Authorization: Bearer sk_sandbox_...

Sandbox keys start with sk_sandbox_ and only work against the sandbox base URL, http://api.paystream.dev.

Create an invoice

POST /v1/invoices
Content-Type: application/json

{
  "customer": "cus_123",      // required: customer id
  "amount": 1999,             // required: integer, smallest currency unit (cents)
  "currency": "usd",          // optional, default "usd"
  "description": "Pro plan"   // optional
}

Returns the invoice:

{
  "id": "inv_...",
  "object": "invoice",
  "status": "open",
  "customer": "cus_123",
  "amount_due": 1999,
  "currency": "usd",
  "hosted_url": "http://pay.paystream.dev/i/inv_..."
}

Errors

Errors return a 4xx status and a body like {"error": {"type": "invalid_request", "message": "..."}}.

Example

curl -X POST http://api.paystream.dev/v1/invoices \
  -H "Authorization: Bearer $PAYSTREAM_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"customer": "cus_123", "amount": 1999, "currency": "usd"}'
